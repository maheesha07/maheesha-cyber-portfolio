# Maheesha Cybersecurity Portfolio

Static responsive portfolio built with HTML, CSS and JavaScript. Uses an original cyberpunk hacker illustration cropped from a generated design concept.

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`.

## Deployment

Upload **all** of `index.html`, `style.css`, `script.js`, and the `assets/` folder together. For Cloudflare Workers static assets, ensure your Worker configuration publishes this directory as the static assets directory. Do not upload `index.html` alone.
